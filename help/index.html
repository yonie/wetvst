Installing

Windows
Copy the .vst3 to C:\Program Files\Common Files\VST3\
macOS
Copy the .vst3 to ~/Library/Audio/Plug-Ins/VST3/ and the .component to ~/Library/Audio/Plug-Ins/Components/ for Logic and GarageBand.
Linux
Copy the .vst3 to ~/.vst3/

Then restart your DAW and let it rescan its plugins.

Making the panel bigger or smaller

Right-click anywhere on the plugin and choose UI Zoom: 75%, 100% or 125%.

Fine adjustments

The knobs click through fixed steps. Hold Shift while you drag, scroll or use the arrow keys to move in smaller steps.

Mono tracks

Every plugin works on mono and stereo tracks. In Logic you can pick the Mono or Mono → Stereo version on a mono channel.

macOS says the plugin cannot be verified

Current versions are signed and notarised by Apple and open without a warning. If an older version is blocked:

  1. Open Terminal: press Cmd + Space, type Terminal and press Return.
  2. Copy this line, paste it into the Terminal window and press Return:

    xattr -cr ~/Library/Audio/Plug-Ins/VST3/Wet*.vst3

  3. If you use Logic or GarageBand, do the same with this line:

    xattr -cr ~/Library/Audio/Plug-Ins/Components/Wet*.component

  4. Close Terminal and restart your DAW.

This clears the download warning for every WET plugin at once; there is nothing to fill in.
