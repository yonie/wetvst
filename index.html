WetDelay

Available

Authentic 80s rack-style digital delay. 100% wet output with vintage 12-bit character and gritty warmth.

  • 6 delay times (20ms to 400ms)
  • 24kHz internal rate, 12-bit quantization
  • Stereo with 1% channel crosstalk
  • Real-time input/output metering
Download Source

WetReverb

Available

Authentic 80s rack-style digital reverb. 100% wet output with vintage 12-bit character and Schroeder-style diffusion.

  • 5 reverb modes (Room, Plate, Hall, Cathedral, Cosmos)
  • 24kHz internal rate, 12-bit quantization
  • Stereo with channel crosstalk
  • Real-time input/output LED metering
Download Source

WetEQ

Available

Authentic British console equalizer. Desk-style saturation, channel crosstalk and gain-dependent Q.

  • 4 bands (LF shelf, LMF bell, HMF bell, HF shelf)
  • HPF, LPF and input GAIN, 17 stepped positions per control - hold Shift for four times finer
  • Host sample rate, no downsampling
  • Real-time L/R input and output LED metering
Download Source

WetCompressor

Available

Authentic 76-style FET compressor, modelled as the circuit. Feedback detector, a gain cell that bottoms out, and distortion that rises with the compression.

  • 3 time constants (Fast, Normal, Slow)
  • Stepped INPUT and OUTPUT, 21 positions each, fixed threshold and ratio
  • Host sample rate, no downsampling
  • Real-time input, gain reduction and output LED metering
Download Source

Why WET VST?

A different approach to plugin development

Fully Open Source

Most free plugins are closed-source binaries. WET plugins give you the complete source code under a permissive license. Learn, modify, contribute.

Pure VST3 SDK

Built directly on the official Steinberg VST3 SDK. No JUCE, no third-party frameworks. Clean, minimal, and easy to understand.

Complete Documentation

Every plugin includes full build instructions using only free tools: Visual Studio Build Tools, CMake, and Git. No paid licenses needed.

Cross-Platform

One binary for all platforms. Windows, Linux, and macOS (Intel & Apple Silicon) supported from day one. Universal VST3 from a single build.
